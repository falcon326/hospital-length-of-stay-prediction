# Dataset Folder

Place your downloaded dataset CSV file (`train.csv` or `LengthOfStay.csv`) from Kaggle into this directory.

- **Source:** [Kaggle - Hospital Length of Stay Dataset Microsoft](https://www.kaggle.com/datasets/aayushchou/hospital-length-of-stay-dataset-microsoft)
- **Target Variable:** `lengthofstay` (Hospital length of stay in days)

---

## About Dataset

This dataset has 100k data points on patients admitted into hospital, indicators of their health condition, and how long they were admitted in the hospital. It has been taken from Microsoft's open-source repository.

- **Full Data Description:** [Microsoft R Server Hospital Length of Stay Documentation](https://microsoft.github.io/r-server-hospital-length-of-stay/input_data.html)
- **Code of Conduct:** [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)

### Dataset Overview
The dataset is useful for predicting length of stay within the hospital. It contains patient demographics, readmission counts (`rcount`), vital health indicators, and various binary comorbidity features (such as asthma, diabetes/renal conditions, etc.).
